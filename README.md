# Memorial MPF — Projeto completo de audiodescrição

Este pacote está pronto para publicação no GitHub Pages.

## Estrutura
- `index.html` — página inicial com a lista das obras
- `obra01-...html` até `obra17-...html` — uma página por roteiro
- `css/styles.css` — estilos acessíveis
- `js/player.js` — controles extras do player
- `media/` — coloque aqui os arquivos de áudio
- `txt/roteiros_formatados.txt` — todos os roteiros em texto corrido acessível
- `mapeamento_obras.csv` — relação entre obra, página HTML e arquivo de áudio

## Publicação no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos desta pasta na raiz do repositório.
3. Vá em `Settings` → `Pages`.
4. Em `Build and deployment`, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve.
7. A URL pública ficará algo como:
   `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## Observações
- Os textos foram apenas formatados para leitura por leitores de tela.
- O conteúdo verbal dos roteiros foi preservado.
- Ao final de cada roteiro foi incluído o crédito:
  `Audiodescritor Consultor: Leonardo Moraes Filho`
