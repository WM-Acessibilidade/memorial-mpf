Memorial MPF — Audiodescrição

Projeto completo para publicação no GitHub Pages, com 17 roteiros formatados, player com controles extras e estrutura pronta para inclusão dos arquivos de áudio.

Como usar

1. Publique este conteúdo em um repositório público no GitHub.

2. Ative o GitHub Pages em Settings → Pages → Deploy from a branch.

3. Envie para a pasta media/ os arquivos de áudio nomeados de audio01.mp3 até audio17.mp3.

4. Abra cada página para testar o player e os textos formatados.

Recursos incluídos

Este projeto já inclui player com botões de voltar 10 segundos, avançar 10 segundos, reproduzir ou pausar, aumentar velocidade e diminuir velocidade.

Também inclui formatação textual com parágrafos curtos e padronização para leitura por aplicativos leitores de tela.

Identidade visual

Esta versão usa aparência inspirada no Memorial MPF e no Ministério Público Federal, com destaque visual para o nome Memorial MPF.

Caso deseje, depois você pode substituir a imagem do cabeçalho por um arquivo oficial hospedado diretamente no próprio repositório.
